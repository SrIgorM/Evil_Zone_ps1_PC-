# Contribuições

Mantenha alterações de desempenho separadas das regras de execução do PS1. Preserve o caminho de referência e apresente medições comparáveis com hardware, configuração e limitações.

Não envie disco, executável comercial, código gerado a partir do jogo, DLLs de overlays, assets, BIOS, saves, credenciais ou logs com dados pessoais. Antes de enviar alterações, execute `python scripts/audit_repo.py`. A auditoria detecta formatos e padrões conhecidos; não substitui revisão humana de procedência e conteúdo.

Relatos de desempenho devem informar Legacy/revisão, CPU, GPU efetivamente usada, RAM, driver, tomada/bateria, modo gráfico, cena e frequência do problema. Não apresente estimativas de requisitos como testes confirmados.
