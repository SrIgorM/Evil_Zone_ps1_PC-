# Requisitos e referências

Os mínimos de desempenho ainda estão em avaliação. Compatibilidade com OpenGL 3.3, por si só, não garante velocidade suficiente.

| Item | Requisito técnico / estimativa |
|---|---|
| Sistema | Windows 10/11 x64, UCRT e driver OpenGL 3.3 |
| CPU mínima | Não determinada; não é possível indicar uma geração mínima comprovada |
| Referência Legacy | Notebook i5-13420H ligado à tomada, aprovado pelo usuário |
| RAM | 4 GB é uma estimativa para testes; 8 GB ou mais é a recomendação provisória |
| GPU | Mínimo não determinado; GPU integrada precisa de teste específico |
| Espaço do pacote privado | Reservar 1 GB por versão extraída, preferencialmente 2 GB para folga e registros |
| Normal 1080p | Requisitos de GPU ainda não medidos; não extrapolar o resultado da Legacy |

A Legacy v3 apresentou cerca de 500 MiB de memória privada comprometida na luta medida. Isso não inclui toda a memória exigida por Windows, drivers e GPU compartilhada. Não significa que 1 GB de RAM total seja suficiente.

O teste em notebook é um relato de uso, não uma medição controlada de consumo energético. A diferença entre bateria e tomada sugere influência do gerenciamento de energia; não identifica isoladamente a causa. Não prometer funcionamento em qualquer PC ou em hardware com apenas a potência de um PS1.
