# Evil Zone PC — Preservation Project

Uma nova maneira de jogar **Evil Zone no PC**, criada por um fã para fãs.

Este projeto foi preparado por mim com o objetivo de preservar o jogo, facilitar sua execução em computadores atuais e apresentar Evil Zone a novos jogadores.

O projeto oferece duas edições diferentes: **Legacy**, que preserva a apresentação original e funciona em máquinas mais simples, e **1080p**, voltada para quem deseja jogar com imagem em alta resolução.

> Projeto independente de preservação, feito sem fins lucrativos e sem vínculo oficial com os criadores ou distribuidores originais de Evil Zone.

## Escolha sua versão

### Evil Zone Legacy

A versão recomendada para computadores simples, notebooks e gráficos integrados.

A Legacy mantém a identidade visual do jogo original, com resolução interna próxima à versão de PlayStation, proporção de tela em 4:3 e imagem mais fiel à experiência clássica.

Principais características:

- Visual próximo ao jogo original.
- Resolução interna original.
- Proporção de tela 4:3.
- Baixo consumo gráfico.
- Compatível com gráficos integrados.
- Indicada para notebooks e computadores básicos.
- Melhor opção para quem busca fidelidade e desempenho.
- Jogo configurado e pronto para executar.

### Requisitos da versão Legacy

| Componente | Requisito mínimo estimado | Recomendado |
|---|---|---|
| Sistema | Windows 10 de 64 bits | Windows 10 ou 11 de 64 bits |
| Processador | Intel Core i3 ou AMD equivalente | Intel Core i5 ou AMD Ryzen 3 |
| Memória RAM | 4 GB | 8 GB |
| Vídeo | Gráfico integrado com OpenGL 3.3 | Intel UHD, AMD Vega ou superior |
| Armazenamento | 1 GB livre | 2 GB livres |
| Arquitetura | Processador x64 | Processador x64 |

Em notebooks, é recomendado jogar conectado à tomada para evitar limitações do modo de economia de energia.

---

### Evil Zone 1080p

A edição para quem deseja jogar Evil Zone com uma apresentação mais moderna.

Essa versão utiliza resolução interna ampliada, antialiasing e filtro de imagem bilinear, proporcionando contornos mais suaves e melhor definição em monitores atuais.

Principais características:

- Resolução interna em 1080p.
- Imagem mais definida.
- Antialiasing ativado.
- Filtro bilinear.
- Janela preparada para telas Full HD.
- Recomendada para computadores com maior capacidade gráfica.
- Jogo configurado e pronto para executar.

### Requisitos da versão 1080p

| Componente | Requisito mínimo estimado | Recomendado |
|---|---|---|
| Sistema | Windows 10 de 64 bits | Windows 10 ou 11 de 64 bits |
| Processador | Intel Core i5 ou AMD Ryzen 3 | Intel Core i5 recente ou AMD Ryzen 5 |
| Memória RAM | 8 GB | 8 GB ou mais |
| Vídeo | Intel Iris Xe, AMD Vega ou placa dedicada equivalente | NVIDIA GTX 1050, AMD RX 560 ou superior |
| Armazenamento | 1 GB livre | 2 GB livres |
| Arquitetura | Processador x64 | Processador x64 |

Os requisitos são referências estimadas. O desempenho pode variar conforme o modelo do processador, placa de vídeo, memória, drivers e configurações de energia.

## Download

Acesse a seção (https://github.com/SrIgorM/Evil_Zone_ps1_PC-/releases/tag/V1.0.0)) e escolha uma das versões:

- `EvilZone-Legacy.zip`
- `EvilZone-1080p.zip`

Cada versão funciona de forma independente e possui suas próprias configurações e arquivos de save.

## Como jogar

1. Baixe a versão desejada.
2. Extraia completamente o arquivo ZIP.
3. Abra a pasta extraída.
4. Execute `EvilZone_Recompiled`.
5. Configure seu controle no menu inicial, caso necessário
6. Importante usar o modo D_PAD

Não execute o jogo diretamente dentro do arquivo ZIP.

## Controles

O jogo aceita teclado e controles compatíveis com o Windows.

Para uma experiência mais próxima do console original, recomenda-se utilizar um controle com:

- Direcional digital.
- Quatro botões principais.
- Botões superiores.
- Start e Select.

O controle pode ser configurado pelo launcher antes de iniciar o jogo.

## Saves

O progresso fica armazenado dentro da pasta `saves`.

Para transferir seu progresso para outro computador:

1. Feche o jogo.
2. Copie a pasta `saves`.
3. Cole-a dentro da pasta da mesma versão no outro computador.

Faça uma cópia de segurança dos saves antes de atualizar ou substituir a instalação.

## Sobre o projeto

Evil Zone é um jogo que merece continuar acessível.

Criei este projeto como fã, com foco em preservação e facilidade de uso. A proposta é permitir que o jogo continue funcionando em computadores atuais, mantendo tanto sua apresentação clássica quanto oferecendo uma alternativa em alta resolução.

A edição Legacy busca preservar a experiência original e alcançar o maior número possível de computadores compatíveis. A edição 1080p oferece uma apresentação mais definida para máquinas com maior capacidade gráfica.

O projeto continuará recebendo melhorias de compatibilidade, desempenho e facilidade de uso.
